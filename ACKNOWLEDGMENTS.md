## Core Technologies

| Technology | Purpose |
|------------|---------|
| **Genblaze** | AI orchestration layer that unifies multiple AI providers into cohesive workflows |
| **Backblaze B2** | Enterprise-grade cloud object storage for persistent campaign assets |
| **OpenRouter** | Unified API gateway providing access to multiple LLM providers |
| **Next.js** | React framework powering the responsive, server-rendered frontend |
| **React** | UI library enabling component-based, declarative user interfaces |
| **TypeScript** | Type-safe development environment for maintainable, scalable code |
| **FastAPI** | High-performance Python web framework for the backend API |
| **Python** | Backend language powering AI processing and data pipelines |
| **Supabase** | PostgreSQL database with real-time subscriptions and authentication |
| **Railway** | Cloud platform hosting the FastAPI backend services |
| **Vercel** | Edge deployment platform for the Next.js frontend |
| **Tailwind CSS** | Utility-first CSS framework for rapid, responsive styling |
| **Framer Motion** | Animation library creating smooth, production-quality interactions |
| **Remotion** | Framework for programmatic video composition using React |
| **Jina AI** | Neural search and web scraping capabilities for market intelligence |
| **ElevenLabs** | Natural-sounding AI voice synthesis for professional voiceovers |
| **Pexels** | High-quality stock media library for campaign visuals |
| **Puter.js** | Client-side cloud storage utilities enhancing the user experience |

## Inspiration

Supernova was inspired by the potential of production-quality AI software to transform how businesses approach marketing. We set out to demonstrate that resilient architectures, autonomous workflows, and cloud-native applications can work together seamlessly—enabling even small teams to execute sophisticated marketing strategies that were previously only possible for large agencies with substantial budgets.

## Project Philosophy

Supernova demonstrates how multiple specialized AI services, enterprise cloud storage, and modern web engineering can work together to automate an end-to-end marketing workflow. By orchestrating intelligent agents for research, writing, design, and production—all backed by persistent cloud storage—we aim to democratize professional marketing capabilities for businesses of all sizes.
